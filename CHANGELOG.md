# Changelog

All notable changes to SMS2Clip are documented here. Release binaries are published on GitHub Releases.

## [0.4.0] - 2026-10-30

- Unified the product name and package structure as **SMS2Clip**.
- Added single-instance manager behavior and automatic listener startup.
- Added configurable verification-code auto-copy and full-SMS Windows notifications.
- Registered a dedicated Windows notification identity and Start Menu shortcut.
- Added persistent message history with full-message viewing, code copy, and clear actions.
- Added manual, tray, and silent startup modes.
- Added connection-settings protection, scrolling, and save-and-apply behavior.
- Improved Chinese and English UI consistency.
- Fixed PyInstaller temporary-directory cleanup when switching to silent mode.

## [0.3.0] - 2026-10-29

- Initial Windows desktop release.
- Added iPhone Shortcut to ntfy forwarding, clipboard ordering, verification-code extraction, tray support, and bilingual UI.
