# Credits and attribution

SMS2Clip is an independent, unofficial secondary development built on top of [ntfy](https://github.com/binwiederhier/ntfy). It uses ntfy's open-source publish/subscribe capabilities to relay messages from an iPhone to a Windows desktop. It is not an official ntfy client and is not affiliated with or endorsed by the ntfy project or its maintainers.

We sincerely thank the ntfy authors and contributors for making their work available.

## iPhone Shortcut

The iPhone Shortcut distributed with this project is a secondary development based on a public ntfy notification Shortcut originally created and shared by **谢週五**. The adapted version is tailored to this project's server/topic setup and verification-code workflow. We thank 谢週五 for the original work and for sharing it publicly.

- Adapted Shortcut: [iCloud Shortcut](https://www.icloud.com/shortcuts/2e72a660dec84fd9b8c7abd92d42043f)
- Upstream project: [binwiederhier/ntfy](https://github.com/binwiederhier/ntfy)
